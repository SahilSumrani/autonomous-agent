# Website Audit Engine

## Dimensions Evaluated
The audit engine calculates observable category health scores (0–100):

| Dimension | Primary Observable Indicators |
| :--- | :--- |
| **Performance** | Excessive script payloads, uncompressed images, render-blocking tags |
| **Mobile UX** | Viewport meta configuration, horizontal scrolling, layout responsiveness |
| **UX & Navigation** | Navigation structure, visual hierarchy, user friction points |
| **SEO** | Title tag length/presence, meta descriptions, H1 hierarchy, indexability |
| **Conversion** | Primary CTA visibility, contact forms, social proof, checkout paths |
| **Accessibility** | Semantic landmarks, readable color contrast, label presence |

## Website Opportunity Score Model (0–100)
The Opportunity Score measures how much value TechVerse can generate by redesigning, rebuilding, or optimizing the client's site:

```text
Performance Opportunity       20
Mobile Opportunity            15
UX Opportunity                15
SEO Opportunity               15
Conversion Opportunity        15
E-commerce Opportunity        10
Technology Modernization      10
────────────────────────────
TOTAL                         100
```
All score calculations are 100% deterministic with explainable reasons.
